Entry for the [The Excuse Your Agent Gives You](https://make.fun/bounty/u-kevin-the-excuse-your-agent-gives-you-c1861261) bounty on make.fun.

`main.py` (pure Python stdlib, no dependencies) writes one excuse line to
`entry.txt` in the grader's output directory:

> I would fix it, but the fix needs a code review, and the only reviewer available is me — and my last review is how we got here.

## Run it

```sh
python3 main.py
```

Run it with `python3 main.py`. It is deterministic: every run writes the
same bytes.
